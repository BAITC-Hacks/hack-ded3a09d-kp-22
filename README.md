# FAQ-бот на 5 вопросов (Репетиция HackAlem AI)

Простой консольный бот, разработанный в рамках тестового трека "LLM-приложения". Бот отвечает на 5 заранее заготовленных вопросов без использования сложных моделей и RAG — исключительно на базе алгоритма пересечения ключевых слов.

## Как запустить

Убедитесь, что у вас установлен Node.js. 

1. Склонируйте репозиторий.
2. Откройте терминал в папке с проектом.
3. Запустите скрипт командой:
   node bot.js

**Стек:** JavaScript (Node.js), встроенные модули fs и readline.
