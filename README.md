# FAQ-бот на 5 вопросов (Репетиция HackAlem AI)

Консольный бот для тестового трека "LLM-приложения". Отвечает на 5 заранее заготовленных вопросов без RAG — только по пересечению ключевых слов. В репозитории два независимых решения от разных участников команды.

## Вариант 1: Python (`bot.py`)

Использует `faq_python.txt`.

```
python bot.py
```
(если `python` не находится — используйте `py bot.py`)

Разбивает вопрос на ключевые слова, отбрасывает стоп-слова (предлоги) и обрезает слова до первых 4 букв, чтобы совпадали словоформы («призы»/«призов»). Выбирает вопрос из FAQ с максимальным числом общих корней, иначе отвечает «не знаю».

## Вариант 2: Node.js (`bot.js`)

Использует `faq.txt` (формат `В: ... / О: ...`).

Убедитесь, что установлен Node.js, затем:
```
node bot.js
```

**Стек:** JavaScript (Node.js), встроенные модули `fs` и `readline`.

## Что получилось

Оба бота верно отвечают на вопросы про время, команду, трек, сдачу и призы при разных формулировках и честно говорят «не знаю» на вопросы не по теме.
