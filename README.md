# FAQ-бот на 5 вопросов

Терминальный бот для репетиции (трек 03, LLM-приложения). Отвечает на 5 заранее известных вопросов, находя ближайший по ключевым словам — без RAG и внешних API.

## Файлы

- `faq.txt` — 5 пар вопрос-ответ (время, команда, трек, сдача, призы) в формате `вопрос|ответ`.
- `bot.py` — сам бот, чистый Python без внешних зависимостей.

## Как запустить

```
python bot.py
```

Windows-консоль иногда путает кодировку кириллицы, поэтому при проблемах с выводом запускайте так:

```
set PYTHONUTF8=1
python bot.py
```

Дальше просто пишете вопрос и жмёте Enter. Выход — `выход`, `exit` или Ctrl+C.

## Как это работает

Вопрос пользователя и каждый вопрос из `faq.txt` разбиваются на слова, отбрасываются стоп-слова (предлоги, вопросительные слова типа «когда», «какой») и обрезаются до первых 3 букв — это заменяет полноценную морфологию и позволяет совпадать словоформам («призы»/«призов»). Бот выбирает вопрос из FAQ с максимальным числом общих «корней». Если общих слов нет — ответ «не знаю».

## Что получилось

Бот верно отвечает на вопросы про время, команду, трек, сдачу и призы, даже при других формулировках и словоформах, и честно говорит «не знаю» на вопросы не по теме.
